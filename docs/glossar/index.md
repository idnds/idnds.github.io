# Glossar

## A

### API {#api}

API steht für Application Programming Interface und beschreibt Schnittstellen, über die externe Anwendungen mit ELO interagieren können, z. B. für Integration von Drittanbietersoftware oder Automatisierung von Prozessen.

### Archivierung {#archivierung}

Archivierung beschreibt das dauerhafte, revisionssichere Speichern von Dokumenten. Dabei werden Compliance-Anforderungen erfüllt und sichergestellt, dass Dokumente nachvollziehbar und unveränderbar gespeichert sind. Oft im Einklang mit gesetzlichen Vorschriften.

## D

### Dynamische Ordner {#dynamische-ordner}

Dynamische Ordner sind Ansichten auf Dokumente, die automatisch anhand von Metadaten oder Filterkriterien gefüllt werden. Anwender sehen so immer eine aktuelle Liste relevanter Dokumente.

## E

### ELO Operator {#elo-operator}

Der **ELO Operator** ist eine zentrale technische Komponente in ELO-Cloud- und Plattformumgebungen, die für die automatisierte Steuerung, Bereitstellung und Aktualisierung von Systemkomponenten verantwortlich ist. Er übernimmt die Orchestrierung von Deployments, Plattform-Updates und Lifecycle-Prozessen innerhalb einer Umgebung und sorgt dafür, dass alle Services in einem definierten, konsistenten Zustand betrieben werden.

Im Rahmen von Wartungs- und Updateprozessen spielt der ELO Operator eine Schlüsselrolle, da er die technischen Änderungen koordiniert und sicherstellt, dass neue Versionen kontrolliert ausgerollt werden können. Dadurch wird ein standardisierter und nachvollziehbarer Update-Prozess ermöglicht, der sowohl Test- als auch Produktivumgebungen umfasst und eine stabile Betriebsbasis gewährleistet.

## K

### Klassifizierung {#klassifizierung}

Dokumentenklassifizierung ist die Zuweisung eines Dokumentes zu einer Kategorie oder einem Dokumententyp anhand von Metadaten oder OCR-Erkennung. Sie erleichtert Suche, Reporting und Zuordnung.

### Kubernetes {#kubernetes}

Kubernetes ist wie ein Dirigent für Anwendungen. Es sorgt dafür, dass sie reibungslos laufen, sich bei Bedarf erweitern und selbst reparieren. Es erleichtert das Management von Anwendungen in der Cloud.

## L

### LTO (Linear Tape-Open) {#lto}

LTO (Linear Tape-Open) ist ein Bandlaufwerk- und Bandmedien-Standard für die langfristige Datensicherung und Archivierung großer Datenmengen. Die Technologie basiert auf magnetischen Bändern und wird vor allem für Backups sowie die revisionssichere, kosteneffiziente Langzeitspeicherung eingesetzt.

LTO zeichnet sich durch eine hohe Speicherkapazität, lange Haltbarkeit der Medien sowie eine gute Eignung für Offline- oder ausgelagerte Datensicherungen aus. Dadurch wird es häufig als zusätzliche Sicherheitsschicht außerhalb der primären IT-Infrastruktur genutzt.

### LTS-Version {#lts}

LTS steht für Long-Term Support und bezeichnet eine Version einer Software, die über einen langen Zeitraum Sicherheitsupdates und Fehlerbehebungen erhält. Für Unternehmen bietet dies Stabilität und Kontinuität.

## M

### Metadaten {#metadaten}

Metadaten sind Informationen über Dokumente, die deren Inhalt, Struktur oder Status beschreiben. Sie ermöglichen effiziente Suche, Filterung und Nutzung.

### MyELO {#myelo}

MyELO ist die personalisierte Benutzeroberfläche von ELO. Nutzer sehen hier ihre Favoriten, Aufgaben und zuletzt genutzten Dokumente.

## O

### OCR (Optical Character Recognition) {#ocr}

OCR ermöglicht die Texterkennung in gescannten Dokumenten, sodass diese durchsuchbar werden.

## R

### Repository {#repository}

Ein Repository ist ein zentraler Speicherort für Dokumente innerhalb der Ablagestruktur in ELO.

### Retention / Aufbewahrungsfristen {#retention}

Retention beschreibt die Dauer, wie Dokumente aufbewahrt werden müssen. ELO kann Aufbewahrungsfristen automatisch verwalten.

## W

### Web Client {#web-client}

Der Web Client ist die browserbasierte Oberfläche von ELO für Dokumentenzugriff und Workflows.

### Workflow {#workflow}

Ein Workflow ist ein definierter Prozess, der Dokumente und Aufgaben automatisch durch Bearbeitungsstufen steuert.
